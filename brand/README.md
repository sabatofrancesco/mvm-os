# Brand

Version-controlled brand documentation and approved identity assets for MVM Packaging.

## Current direction

- Payoff: **Primary Packaging for Beauty Brands**
- Positioning: **Primary Packaging Partner**
- Audience: premium skincare and beauty brands
- Personality: elegant, competent, contemporary, discreet luxury
- Preferred core visual direction: navy with white/gold applications

The approved geometry of the **V** is locked. Do not alter it without explicit approval.
