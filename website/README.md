# MVM Packaging Website

Next.js website for `mvmpackaging.com`.

## Current home structure

- Header
- Hero
- Why MVM
- Featured Collection
- Development Process
- Final CTA
- Footer

## Product direction

The website should ultimately consume a controlled/publishable subset of the Notion product catalogue rather than maintaining a second manual product database in source code.

## Development

```powershell
npm install
npm run dev
```

## Priorities

1. Finalize brand assets and typography.
2. Define navigation and product-category architecture.
3. Add catalogue data model and publishing workflow.
4. Add product listing and product-detail pages.
5. Add contact / sample / quotation request flows.
6. Add SEO metadata and analytics.
7. Connect deployment to Vercel and `mvmpackaging.com`.

## Content principles

MVM should present itself as a **Primary Packaging Partner** for beauty brands: premium, technically competent and easy to work with. Product information published online must come from verified catalogue data.
