# Prompts

Reusable AI operating instructions for MVM Packaging.

Prompts stored here should support repeatable workflows such as:
- product-data extraction and validation
- catalogue normalization
- prospect research
- commercial email drafting
- LinkedIn content generation
- website copy generation
- technical-document classification

## Rules

- Keep prompts provider-neutral where practical.
- Document expected inputs and outputs.
- Never include passwords, API keys, personal credentials or confidential customer information.
- Prefer structured outputs when prompts feed automated workflows.
